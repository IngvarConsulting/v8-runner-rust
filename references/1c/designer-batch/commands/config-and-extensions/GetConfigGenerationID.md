# GetConfigGenerationID

## Назначение

Получения идентификатора текущего "поколения" метаданных конфигурации. Данный идентификатор обновляется при любом изменении конфигурации. Идентификаторы, полученные с помощью данной команды, имеет смысл сравнивать только на "равно`/не` равно" для проверки наличия изменений в конфигураторе с момента последнего получения конфигурации.

## Синтаксис

```text
/GetConfigGenerationID [-Extension <имя расширения>]
```

## Параметры

- `-Extension <имя расширения>` — получение идентификатора метаданных указанного расширения. Если параметр не указан, идентификатор получается для основной конфигурации.

## Связи

- Для получения идентификатора следует обязательно указывать команду `/Out` командной строки запуска конфигуратора.
- Идентификаторы, полученные с помощью данной команды, имеет смысл сравнивать только на "равно`/не` равно" для проверки наличия изменений в конфигураторе с момента последнего получения конфигурации.

## Примечания

- Идентификатор имеет вид `4d8d1d994cd4534c9accd32a5b44b35300000000`.
- Для пустой информационной базы идентификатор имеет вид `0000000000000000000000000000000000000000`.
- Команда реализована в платформе 8.3.20 (список изменений платформы 8.3.20, V8Update.htm).
  Платформа старше команды ключ не узнаёт: пакетной операции в запуске нет, Конфигуратор
  открывает окно в интерактивном режиме и сам не кончается — `/Exit` ждёт конца пакетного
  задания, которого нет ([замер](../../../confirmed-runtime-measurements.md) 03.11.2026 на
  8.3.12). Поэтому раннер платформу старше 8.3.20 о поколении не спрашивает.
