# Публикация не входит ни в одну цепочку умолчаний

**Решение.** Ни `build`, ни `test`, ни любая другая команда не выполняет
публикацию попутно и не чинит сломанную. Публикация — отдельное намерение
пользователя и делается отдельной командой.

**Почему.** Публикация меняет состояние веб-сервера вне рабочего каталога и
замещает его файл описания целиком. Побочный шаг с такими последствиями внутри
сборки нарушил бы обещание превью: «покажи, что сделаешь» перестало бы перечислять
всё, что будет сделано.

**Не затрагивает.** Сценарии, где публикация нужна: они называют её шагом явно.
