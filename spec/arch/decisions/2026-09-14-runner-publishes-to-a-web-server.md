# Публикацию на веб-сервере делает раннер

**Решение.** Появляется команда `v8-runner publish` с провайдером `webinst` и
парная `publish --delete`; обе имеют превью. Параметры берутся из секции
`infobase.web` (`server`, `wsdir`, `dir`, `conf`, `os-auth`, `url`), а не из
флагов: публикация должна воспроизводиться из файла. Работает для файловой и
кластерной базы; автономному серверу публикация не нужна — он отдаёт HTTP сам.
Развилки у операции нет, поэтому `providers.publish` валидация отклоняет.

**Почему.** Чтобы проверить веб-клиент на кластерной или файловой базе,
публикацию до сих пор делали руками, хотя в составе платформы для этого есть
`webinst`, принимающая обычную строку соединения.

**Цена.** Предусловия инструмента переносятся на пользователя и должны быть
названы до запуска: права администратора, существующий каталог, `-osauth` только
для IIS, `-confpath` обязателен у Apache 2.0 и 2.2. Существующий `default.vrd`
замещается целиком — поэтому у команды обязательно превью, а удаление идёт
отдельным явным ключом.
