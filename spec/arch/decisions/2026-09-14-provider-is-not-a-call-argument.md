# Провайдера нет ни на проводе, ни во флагах

**Решение.** Провайдер не является аргументом MCP-инструмента, флагом CLI или полем
запроса. Публичного `--provider` не вводится; `init --builder` снимается вместе с
ключом `builder`.

**Почему.** Флаг CLI доступен модели ровно так же, как поле MCP: через запуск
команды. Выбор исполнителя — знание о платформе, а не предпочтение вызывающего, и
единственное место, где его законно записать, — файл проекта, видимый в diff.

**Не затрагивает.** Диагностику: квитанция называет выбранного провайдера и
пропущенных, поэтому вызывающий видит решение, даже не имея права его принимать.
