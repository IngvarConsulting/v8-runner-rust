# Греет сессию EDT только долгоживущий хост

**Решение.** Заблаговременный прогрев общей сессии EDT включается лишь там, где
процесс живёт между вызовами, — у MCP-сервера. Короткая команда CLI поднимает
сессию лениво, при первом обращении, и держит её только в своих границах.

**Почему.** Прогрев окупается переиспользованием. Для команды, которая завершится
через минуту, он лишь добавляет секунды к старту и оставляет висящий процесс, если
работа закончилась раньше готовности.

**Не затрагивает.** Выбор одного из двух режимов исполнения EDT: прогрев — это
политика владельца сессии, а не третий режим.
