# Каталог вне системы контроля версий не заменяется молча

**Решение.** Третий ответ системы контроля версий — «ответа нет»: гита нет, каталог не
репозиторий, вызов не удался — трактуется как отказ на тех же правах, что найденное
безвозвратное. Весь каталог, если он под контролем версий не находится, считается
разрушением; изменение зафиксированного файла разрушением не считается. Явный выход один
— `--force` с перечислением уничтоженного; `--dry-run` перечисляет поимённо, ничего не
трогая.

**Почему.** Прежнее решение оставляло незнание без защиты и говорило об этом вслух:
приравнять незнание к угрозе значило бы запретить работу тем, кто держит исходники вне
системы контроля версий, а настоящим ответом для них называлась память раннера о том,
что он сам породил. Эта память появляется только после первого обмена, не видит файлов
вне своего учёта и может оказаться чужой или устаревшей
(`DEC.2026-09-21.MEMORY-IS-KEPT-PER-INFOBASE`); свидетелем безвозвратности она быть не
может. Свидетель один — система контроля версий, и целевая модель выбирает отказ с явным
выходом вместо молчаливой замены.

**Цена.** Каталог вне системы контроля версий получает отказ на каждом `pull` и
`convert` без `--force`.

**Не затрагивает.** Сам вопрос и два первых ответа —
`DEC.2026-09-21.UNRECOVERABLE-WORK-IS-ASKED-OF-VERSION-CONTROL`.
