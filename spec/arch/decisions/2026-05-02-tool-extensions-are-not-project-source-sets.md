# Инструментальное расширение не входит в состав проекта

**Решение.** Расширение, нужное самому инструменту, готовится общим внутренним
механизмом: у него есть имя в базе и ровно один источник — исходники или готовый
артефакт. В наборы проекта оно не добавляется, в их порядок не входит и через
выбор набора не адресуется. Готовится оно на стадии сборки, а не запуска клиента.

**Почему.** Набор — проектная единица с собственной идентичностью и состоянием.
Служебное расширение, попав в этот список, меняло бы состав продукта и порядок
шагов ради нужды инструмента.

**Не затрагивает.** Проектные расширения: они остаются наборами.
