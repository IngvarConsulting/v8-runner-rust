# У контракта есть проверяемый пример

**Решение.** Каждый контракт несёт раздел «Пример» с блоком кода, и этот пример
проверяется машиной. Если артефакт контракта — схема, пример обязан её пройти целиком;
если артефакт — закреплённый документ, пример обязан быть его фрагментом. Реестр
отклоняет контракт без такого раздела, а страж — контракт, чей пример своей же форме
не соответствует.

**Почему.** Схема отвечает на вопрос «что допустимо», а читателю нужен ответ на вопрос
«как это выглядит»: по экземпляру видно то, чего не видно по перечню полей, — какие
значения там бывают на самом деле. Непроверяемый пример эту работу делает ровно до
первой смены формы, после чего врёт там, где ему верят больше всего.

**Цена.** Пример приходится держать полным: у закрытой схемы экземпляр без
обязательного поля её не проходит, поэтому короткий фрагмент «для иллюстрации» не
годится. Записи стали длиннее.

**Не затрагивает.** Решения и инварианты: у них нет закреплённой формы, проверять
пример не обо что.
