# Превью показывает план и останавливается до запуска

**Решение.** Превью проходит ту же проверку запроса и тот же поиск утилиты, что и
обычный запуск, называет предмет и останавливается до запуска процесса. Оно не
создаёт ни целей, ни артефактов, ни промежуточных каталогов, ни рабочего
пространства, ни состояния обнаружения изменений — это проверяется по отсутствию
файлов, а не по отсутствию вызова. Отсутствие платформы отказывает до одобрения
плана, а не после.

**Почему.** Одобрять изменение базы вслепую нельзя, а «пробный запуск» без
остановки и есть обычный запуск.

**Не затрагивает.** Строку в журнале действий: она остаётся, превью не прячется.
