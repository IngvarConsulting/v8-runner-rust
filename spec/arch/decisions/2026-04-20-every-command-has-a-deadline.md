# У каждой команды есть срок

**Решение.** Каждая публичная команда имеет предельное время выполнения. Срок
покрывает весь жизненный цикл: ожидание допуска, подготовку, внешний процесс, сбор
журналов, очистку и раскладку результата. Вложенная оркестрация наследует остаток
срока внешней команды и своего не заводит.

**Почему.** Точечные таймауты у отдельных шагов оставляли команду без общего
предела: сумма шагов, каждый из которых уложился, могла висеть неограниченно.

**Не затрагивает.** Отдельные таймауты инструментов: они уточняют шаг, но общий
срок не заменяют.
