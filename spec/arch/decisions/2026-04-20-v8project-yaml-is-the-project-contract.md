# Проект описывает один типизированный файл

**Решение.** `v8project.yaml`, загруженный в типизированную модель и прошедший
валидацию, — главный конфигурационный контракт проекта. Неподдержанные и опасные
сочетания отклоняются на границе валидации, до вызова платформы. Альтернативный
вход в конфигурацию либо отображается в ту же модель, либо заводится отдельным
решением.

**Почему.** Свободная схема расползается: документы начинают описывать разные
варианты одного контракта, а ошибка обнаруживается посреди работы с базой, когда
часть шагов уже выполнена.

**Не затрагивает.** Машинные настройки: для них есть локальный слой поверх этого
файла.
