# Конвертация идёт по наборам проекта, а не по произвольным путям

**Решение.** Конвертация форматов исходников — команда CLI над наборами текущего
проекта: без выбора обрабатываются все в конфигурационном порядке, с выбором —
один названный. Направление берётся из формата проекта. Команда не зависит от
выбора исполнителя и не требует информационной базы. Произвольные пути источника и
цели в аргументах не принимаются.

**Почему.** Путь в аргументе обходит контракт проекта: конвертируется то, что не
описано конфигом, а результат не связан ни с одним набором.

**Не затрагивает.** Выгрузку из базы: это другое намерение и другая команда.
