# Статус — закрытый перечень

**Решение.** `status` принимает `active`, `planned` и `superseded`; значение вне перечня
реестр отклоняет. Проверка одна на все три вида: поле общее, ветки по виду у него нет.
Пустое значение остаётся прежней претензией — про отсутствующее гейт говорит один раз и
своими словами.

**Почему.** `DEC.2026-09-16.GOVERNS-IS-A-CLOSED-AXIS` закрыл вторую общую ось по тем же
причинам; статус остался открытым, а решает он больше. Гейт читает поле точным
равенством, поэтому `status: activ` не отвергался, а оказывался «ни тем ни другим», и
проверка, которая ветвится на `active`, молча переставала применяться: правило со
`status: activ` уходило из-под «действующее правило ссылается на недействующее решение» и
оставалось в дереве поверх непринятого решения. Глазами опечатку не поймать — индекс
печатает значение как есть, и колонка «Статус» выглядит заполненной, — а grep по `active`
её не находит.

**Цена.** Четвёртое состояние записи заводится правкой кода и README, а не одной записью.
Цена взята сознательно: статус решает, какие проверки к записи применяются, а не
описывает её.

**Не затрагивает.** `scope`: его перечень README называет открытым, дрейф там виден в
индексе и стоит дешевле запрета. `status: superseded` у правила: реестр его принимает,
хотя правила правят, а не заменяют, — это отдельный предмет.
