# У EDT ровно два режима исполнения

**Решение.** Либо каждый вызов запускает отдельный процесс EDT CLI, либо
поддержанные команды идут через одну общую живую сессию с очередью, сбросом
базового состояния перед пользовательской командой, перезапуском и дренажом при
завершении. Третьего режима — интерактивного, но не общего — не существует.

**Почему.** Интерактивная сессия, создаваемая в каждом вызове, уже не одноразовый
запуск, но ещё не общая сессия с едиными правилами перезапуска и отмены. Такой
промежуток удваивал бы пути исполнения без пользы для вызывающего.

**Не затрагивает.** Время жизни общей сессии: оно решается тем, кто её держит.
