# Поле имеет ту форму, которую публикует README

**Решение.** Поле, объявленное перечнем, несёт перечень; поле, объявленное одним
значением, перечнем не бывает. Форма сверяется раньше смысла, а всё, что от неё зависит,
за неё и прячется: значение не той формы не судится по существу, потому что судить нечего.

**Почему.** Форму README публикует наравне со смыслом, а проверки читали её как известную,
и расхождение оборачивалось не отказом, а неверным «принято». `establishes` скаляром
превращал обратную проверку в поиск подстроки: решение, заводящее `INV.DOCS.EXAMPLE-LONGER`,
удостоверяло `INV.DOCS.EXAMPLE`, которого не заводило. `superseded-by` перечнем называл
двух преемников там, где обещан один. `id` или `decision` перечнем роняли разбор всего
реестра — ошибка про одну запись превращалась в трассировку, и гейт не судил ни одной.

**Цена.** Подмножество YAML сужается ещё: где README обещает символ, перечень теперь
отказ, даже из одного элемента. Автору это стоит одной правки, читателю проверок — права
считать форму известной, а не угадывать её по значению.

**Не затрагивает.** `check` и `realized`: одно правило держат и один адрес, и несколько,
и README теперь говорит это прямо, а не обещает один адрес. Значения полей: форму реестр
знает, а перечень `scope` по-прежнему открыт.
