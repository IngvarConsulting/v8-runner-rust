# Структурный вывод включается одним флагом

**Решение.** Единственный публичный переключатель структурного вывода — булев
`--json-message`. Без него печатается человекочитаемый текст. Путь результата
команды называется `--output`; отдельные имена для того же смысла не вводятся.

**Почему.** Два имени для одного смысла заставляют помнить, какая команда какое
слово понимает, а имя `--output` в роли и формата, и пути результата означало бы
две разные вещи одним словом.

**Не затрагивает.** Состав вывода: он один для обоих форматов.
