# Загрузка базы требует названного режима цели

**Решение.** Возврат базы из переносимого файла принимает ровно один явный режим:
создать отсутствующую базу или заменить существующую. Режим обязателен и
проверяется против наблюдаемой цели: создание при существующей базе и замена при
отсутствующей отклоняются как неверный аргумент. Молчаливого перехода к другому
случаю нет.

**Почему.** Замер показал, что провайдеры расходятся: по отсутствующей цели один
создаёт базу, другой отказывает, а существующую оба заменяют молча. Режим на
стороне раннера делает исход одинаковым независимо от того, кто выбран.

**Не затрагивает.** Серверную цель без процесса: там наличие базы наблюдать нельзя,
режим принимается на слово, а последнее слово остаётся за платформой.
