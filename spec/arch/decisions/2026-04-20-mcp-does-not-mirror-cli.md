# MCP не зеркалит CLI

**Решение.** CLI и MCP — самостоятельные публичные поверхности. MCP публикует
заведомо более узкий набор инструментов, и появление команды в CLI само по себе не
создаёт инструмента MCP. Добавление, удаление, переименование или смена смысла
инструмента — изменение публичного контракта и требует отдельного решения.

**Почему.** Автоматическое зеркало сделало бы любое расширение CLI неявным
расширением агентской поверхности: она росла бы без обсуждения, а клиенты MCP
получали бы инструменты, за которые никто не отвечал.

**Не затрагивает.** CLI-only команды: их существование законно и недоделанностью
MCP не является.
