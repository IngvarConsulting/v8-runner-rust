# Тип набора определяется по содержимому маркеров

**Решение.** Создание конфига определяет формат и тип каждого набора только по
содержимому маркер-файлов, а не по именам каталогов. Внешние обработки и отчёты
находятся лишь как однородный агрегатный корень допустимых дочерних проектов;
рекурсивный обход описателей, откат по одному артефакту и выдуманные наборы
запрещены. Если конфигурационный набор не найден, команда отказывает, а не пишет
пустышку.

**Почему.** Имя каталога — соглашение, а не факт. Определение по имени однажды
назовёт расширением обычную конфигурацию, и ошибка вылезет при первой же загрузке
в базу.

**Не затрагивает.** Право пользователя описать наборы вручную.
