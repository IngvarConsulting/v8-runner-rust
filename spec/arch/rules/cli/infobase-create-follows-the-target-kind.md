# Базу создаёт `infobase create`, и делает это по виду цели

Файловую базу `ibcmd` создаёт сразу с конфигурацией из исходников. В кластере Конфигуратор
одной командой регистрирует базу и создаёт базу данных в СУБД, реквизиты берутся из секции
`dbms` и `cluster.user`; `rac` — запасной путь. Автономный сервер получает отказ рода
подбора с рецептом.

Для формата EDT команда создаёт ещё и рабочую область. Созданная база сразу записывается в
память, поэтому первая отправка после неё — обычная. Существующая база — отказ на тех же
правах, что у подъёма из снимка с созданием.
