## 2. Ограничения

- Утилиты платформы внешние: `1cv8`, `1cv8c`, `ibcmd`, `webinst` раннер находит по версии
  или маске из `tools.platform`, `1cedtcli` — по `tools.edt_cli`, а сам их не ставит. Как
  они ведут себя на деле, записано в
  [замерах на живой платформе](../../references/1c/confirmed-runtime-measurements.md).
- Шлюзу автономного сервера и чужому агенту Конфигуратора локальная платформа не
  требуется: раннер говорит с ними по SSH.
- Одна машина. Раннер работает там, где лежат исходники и `workPath`; удалёнными бывают
  база, чужой агент, шлюз, GitHub Releases для `tools download` и клиенты MCP по HTTP.
- ОС — Windows, Linux и macOS. Что CI проверяет на каждой, записано в
  [`scripts/test/README.md`](../../scripts/test/README.md).
- Rust, редакция 2021, минимальная версия — в `Cargo.toml`; один бинарный крейт. MCP —
  `rmcp`, `tokio`, `axum`; SSH — встроенный клиент `russh`.
- Хранилища секретов нет: пароли лежат открытым текстом в местном слое конфигурации.
