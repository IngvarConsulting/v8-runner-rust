# У принятой цели есть адрес памяти

Всякая цель, которую принимает проверка конфигурации, — файловая база, база в кластере,
автономный сервер — имеет адрес, к которому привязана память о ней. Формы, у которых такого
адреса нет (например, адрес веб-клиента `ws=…`), проверка отвергает до любой команды, в том
числе до `push --force`: базы без памяти «навсегда» не бывает.
