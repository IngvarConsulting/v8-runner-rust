# Управляемый агент работает в своём каталоге

Конфигуратор в агентском режиме при первой сессии пишет файл настроек пользователя
(`1cv8u.pfl`) в свой текущий каталог. Поэтому раннер запускает управляемого агента с
текущим каталогом внутри `workPath`, а не в каталоге, откуда запущен сам: рабочая копия
проекта после команды не получает файлов, которых не просили.
