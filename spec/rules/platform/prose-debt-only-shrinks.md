# Реестр решений по прозе может только сокращаться

Страж разбирает продуктовый код и находит места, где решение принимается по тексту ответа
инструмента. Объявленный долг может только уменьшаться: новое место валит проверку,
исчезнувшее — тоже, чтобы реестр не превращался в историю.

Новая проверка результата внешнего инструмента заводится так:

1. Назвать структурный ответ, на котором принимается решение: код выхода, обещанный
   артефакт или документированный машинный вывод. Формулировка вывода входом решения быть
   не может — платформа пишет один и тот же факт на трёх языках, и фразу её разработчик
   вправе переписать в исправительном выпуске
   ([замеры](../../../references/1c/confirmed-runtime-measurements.md)).
2. Если структурного ответа нет, взять факт у вызывающего и назвать неизвестность
   отдельным значением, а не выводить её из текста.
3. Прозу инструмента донести до вызывающего как улику, не интерпретируя.
4. Снять замер на настоящем инструменте и записать его версию рядом с правилом.
   Поддельный инструмент в тестах повторяет замер, а не собственную выдумку: образец —
   `src/platform/extension_inventory.rs::MEASURED_LIST`.
