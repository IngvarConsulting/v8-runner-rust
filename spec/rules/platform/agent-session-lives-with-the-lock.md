# Агентская сессия живёт ровно столько, сколько замок

Исполнитель `agent` открывает сессию при захвате блокировки рабочего каталога и закрывает
её при освобождении. Вложенная оркестрация идёт в той же сессии: у сборки загрузка
исходников и обновление конфигурации базы — два шага одного разговора, а не два процесса.

У долгоживущего MCP-сервера между вызовами живёт сессия EDT; агентская по-прежнему
открывается под замок конкретной команды.
