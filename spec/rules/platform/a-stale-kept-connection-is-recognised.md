# Устаревшее подключение живого агента узнаётся по замеренному ответу платформы

Живой агент держит подключение к базе между командами
(`INV.PLATFORM.A-LIVE-AGENT-STAYS-CONNECTED-BETWEEN-COMMANDS`), и оно может устареть:
администратор завершил сеанс агента, перезапустили кластер или СУБД базы. Сторож узнаёт такое
подключение по ответу платформы, замеренному для каждого из этих случаев, и переподключает
агента, а не отдаёт команде отказ платформы.
