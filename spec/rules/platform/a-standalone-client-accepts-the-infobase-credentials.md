# Клиент автономного сервера принимает реквизиты базы

Тонкий клиент и интерактивный Конфигуратор открывают базу автономного сервера с
пользователями по строке прямого шлюза `/S <host>:<port>\<name>` с `/N` и `/P`, а тонкий
клиент — и по клиентскому адресу `/WS` с теми же ключами. Замер #178 видел сеанс тонкого
клиента по `/S` в базе без пользователей; база с пользователями, интерактивный
Конфигуратор и `/WS` автономного сервера не замерены.
