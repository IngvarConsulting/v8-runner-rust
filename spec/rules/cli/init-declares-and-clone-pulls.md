# `init` объявляет проект, `clone` его выгружает

`init` заводит проект здесь: находит наборы исходников, пишет проектный файл и местный
слой, наружу не выходит. По умолчанию объявляет `origin` файловой базой внутри рабочего
каталога; с названным адресом записывает его и базу не трогает.

`clone` — это объявление и выгрузка одной командой в пустом каталоге; непустой каталог
даёт отказ. Базу не создаёт ни одна из двух: это `infobase create`.
