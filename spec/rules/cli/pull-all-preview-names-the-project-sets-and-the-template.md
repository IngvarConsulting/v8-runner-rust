# Превью `pull --all` называет наборы проекта и шаблон новых

Превью `pull --all` платформу не запускает и потому состава базы не знает: список новых
наборов известен только настоящему прогону. Превью называет существующие наборы и шаблон
новых: превью выгрузки — у набора основной конфигурации, который прогон выгрузит при любом
составе базы; наборы расширений проекта — в `data.if_installed`, без превью выгрузки,
потому что прогон выгрузит лишь те, чьё расширение есть в базе; объявляемые — шаблоном
`src/ext/<Name>` в сообщении. `declared` у превью `null`. Ничего не пишется.

Критерий задачи #344 «превью перечисляет наборы, которые были бы объявлены» заменён этим
решением владельца (06.10.2026).
