# `reset` отбрасывает непринятое, не трогая базу данных

Команда возвращает основную конфигурацию к конфигурации базы данных и саму базу данных не
трогает — это обратный ход применения. У расширения своя пара.

Своё непринятое — отправленное без применения, что видно по памяти о поколении, —
отбрасывается молча; чужое, сделанное в Конфигураторе, — только с `--force`. Без памяти о
поколении всё непринятое считается чужим. Исполнители — Конфигуратор и `ibcmd`; в наборе
SSH-шлюза отката нет.
