# Базу создаёт `infobase create`, и делает это по виду цели

Без `--from` файловую базу `ibcmd` создаёт сразу с основной конфигурацией из исходников.
В кластере Конфигуратор одной командой регистрирует базу и создаёт базу данных в СУБД,
реквизиты берутся из секции `dbms` и `cluster.user`; `rac` — запасной путь. Автономный
сервер получает отказ рода подбора с рецептом.

Для формата EDT команда создаёт ещё и рабочую область. Созданная так база сразу
записывается в память: у файловой — набор, из которого она собрана, и первая отправка
досылает остальное; у базы в кластере, которую Конфигуратор создаёт пустой, — только то, что
база есть, и первая отправка полная. Копию другой базы делает `--from`
(`INV.CLI.INFOBASE-CREATE-FROM-COPIES-A-BASE`). Существующая база — отказ на тех же
правах, что у подъёма из снимка с созданием.
