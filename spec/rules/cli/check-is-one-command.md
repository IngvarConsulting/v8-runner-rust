# Проверка конфигурации — одна команда с ключами, без подкоманд

`check` принимает режимы ключами и подкоманд не имеет. Для формата платформы это
`/CheckConfig` со всеми режимами — целостность, ссылки, синтаксис, обработчики,
модальность, расширенная проверка модулей; для формата EDT — проверка проекта средствами
EDT CLI, и база тогда не нужна.

Отдельного пути `/CheckModules` на поверхности нет. Состав режимов остаётся платформенным
и перечисляется в справке команды.
