# `push --delete` сначала выключает расширение, потом удаляет

`push --delete <ссылка>` снимает с расширения активность и только затем удаляет его. Данные
расширения при удалении теряются безвозвратно ([замер](../../../references/1c/confirmed-runtime-measurements.md)), поэтому подтверждение
спрашивает сам раннер и прямо называет эту потерю. Оба шага выполняет `ibcmd`: вопрос
платформы об удалении раннер подтверждает сам через псевдотерминал, потому что ключа
подтверждения у `ibcmd` нет. Агент удаление после снятия активности не проходит, а у
пакетного Конфигуратора нет первого шага; они отвечают отказом, и разрыв назван в документах
по `INV.USE-CASES.AN-EXECUTOR-GAP-IS-NAMED-IN-THE-DOCS`.

Источник: [`platform.html#t42`](../../../docs/site/platform.html#t42).
