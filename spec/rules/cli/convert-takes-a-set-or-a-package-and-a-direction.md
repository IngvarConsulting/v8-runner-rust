# `convert` принимает набор или файл пакета и направление

Позиционный аргумент — набор исходников проекта или файл пакета: аргумент с расширением
`.cf` или `.cfe` считается файлом, остальное — именем набора. `--source-set <имя>`
остаётся скрытым синонимом позиционного набора на один цикл выпуска.

`--to xml|edt|package` задаёт направление: XML платформы, проект EDT или пакет. Без `--to`
направление берётся из формата проекта, как раньше. EDT ↔ XML выполняет `1cedtcli`; для
направлений с пакетом есть цепочка исполнителей `ibcmd` → `ibcmd-rs`, и квитанция называет
выбранного. Отсутствие инструментов отвечает по
`INV.WIRE.A-MISSING-TOOL-IS-AN-ENVIRONMENT-FAILURE`. Направления с пакетом меняют форму
`CTR.WIRE.CONVERT-DATA`, и её версия растёт вместе с этой работой.
