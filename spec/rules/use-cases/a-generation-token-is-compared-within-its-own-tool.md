# Токен поколения сравнивается только внутри своего инструмента

Ответом на вопрос «менялась ли база» считается только токен того же инструмента, которым
получен записанный. Токен другого инструмента — отсутствие ответа, а не расхождение и не
совпадение: токен одного и того же расширения у Конфигуратора и `ibcmd` различается
([замер](../../../references/1c/confirmed-runtime-measurements.md)). Токен пустой базы сравнивается как любой другой.

Сегодня журнал `workPath/infobases/<база>/generation.json` (запись на набор) пишет только
агент, и сравнение выходит внутри одного инструмента лишь поэтому: имени инструмента запись
не несёт.
