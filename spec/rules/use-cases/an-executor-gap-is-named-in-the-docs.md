# Пробел в матрице исполнителей назван в документах

Для файловой базы и кластера проверка выполняется отдельно. Операция, у которой на
проверяемой цели есть исполнитель `designer`, но нет `ibcmd` —
ни готового, ни экспериментального, — или наоборот, названа в разделе «Пока не
поддерживается» `docs/CAPABILITIES.md` строкой «`<команда>` через `<исполнитель>`».

Если пробел есть только у файловой базы или только у кластера, строка уточняет «на файловой базе»
или «на кластерной базе»; без уточнения она относится к обоим. Лишних строк этого вида нет.
