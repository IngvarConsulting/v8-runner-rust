# Загрузка частичная, если есть с чем сравнить

`push` загружает только изменённое, когда у набора есть память, и порога числа файлов нет.
Правка корневого описания `Configuration.xml`, новый объект и удаление объекта идут частичной
загрузкой вместе с `Configuration.xml`: новый объект — с файлами объекта, удалённый — без них;
удалённые пути в список не входят. Так платформа добавляет и удаляет объекты частичной
загрузкой, в том числе под хранилищем конфигурации, где полная загрузка невозможна
([замер](../../../references/1c/confirmed-runtime-measurements.md)).

Замер пока не покрыл удаление подчинённого файла, на который XML объекта не ссылается, новый
объект с подкаталогами и раскрытие изменённого каталога в файлы, удаление через `ibcmd` и
агента вне хранилища, расширение формата Конфигуратора и длинный список у `ibcmd`. Пока
замера нет, эти случаи идут полной загрузкой.

Полная загрузка остаётся там, где сравнивать не с чем или её требует другое правило: у набора
нет памяти при памяти о базе; явный `push --full`; первая отправка после создания базы в
кластере (`INV.CLI.INFOBASE-CREATE-FOLLOWS-THE-TARGET-KIND`) и после копии
(`INV.USE-CASES.A-COPIED-BASE-STARTS-WITH-A-FULL-PUSH`); расширение формата EDT; изменение
вне корня набора (`INV.USE-CASES.A-CHANGE-OUTSIDE-THE-SOURCE-ROOT-TURNS-THE-LOAD-FULL`);
восстановимый сбой анализа изменений.
