# Неизменившееся поколение не выгружается

Инкрементальная выгрузка через агента, увидев поколение, равное записанному
после последней удачной загрузки или выгрузки, отвечает успехом с сообщением и не
отправляет агенту команду выгрузки.

Полная выгрузка по поколению не пропускается: она получает дерево, и оно становится
хеш-памятью базы. Журнал поколения не подтверждает, что локальные файлы совпадают с базой.
