# Долгая команда агента показывает ход работы

Ответа агента раннер ждёт столько, сколько агент работает: срок простоя живого агента
ожидание не прерывает (`INV.PLATFORM.A-LIVE-AGENT-CLOSES-WHEN-NOBODY-HOLDS-IT`). Пока ответа
нет, раннер передаёт ход работы, о котором сообщает агент. Человеку при выводе текстом он
показывает строки хода. При ответе JSON ход идёт отдельным потоком событий и в итоговый
JSON не попадает. Как выглядят события, ещё предстоит спроектировать; оно станет своей
закреплённой формой.
