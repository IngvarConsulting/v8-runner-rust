# Чужая память не используется

Память под именем базы, записанная для другой базы, объявляется чужой в ответе и не даёт
основания пропустить работу.

Для хешов привязка и содержимое снимка записываются атомарно; адрес не содержит
учётных данных, а исполнитель не участвует в сравнении. Обычная отправка отказывает
при чужой хеш-памяти и предлагает полный `pull`. Привязка остальных видов памяти
остаётся в #214.
