# Отправка расширения сверяет загруженную конфигурацию

Чужая загрузка расширения без применения должна обнаруживаться при сверке поколения перед
`push` без `--force`. Отправка отклоняется с `non_fast_forward` до первой загрузки, а `status --deep`
показывает расхождение. Токены применённой и загруженной конфигураций нельзя сравнивать между
собой: агент и пакетный Конфигуратор читают применённое поколение, а `ibcmd` — загруженное.
