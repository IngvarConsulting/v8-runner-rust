# Описание проекта имеет одного владельца

Рендеры проектного файла и местного слоя — единственное место, где сказано, каким проект
будет. Превью заведения проекта настроек отдельно не собирает: оно разбирает вывод тех же
рендеров в памяти, поэтому названные им настройки дословно равны прочитанным с диска после
боевого прогона.

Выгрузку превью планирует та же `dump_config`, что и выполняет: режимы различает признак в
запросе, а не второй поиск утилиты.
