# `ibcmd` снимает и загружает `.dt` только при монопольном доступе

`ibcmd`, названный ключом `providers.infobase.dump|restore`, запускается для файловой базы
лишь после того, как раннер убедился в монопольном доступе к ней: активных соединений нет
либо раннер получил монопольный доступ, не завершая чужих сеансов. При открытом сеансе
команда отказывает до запуска `ibcmd infobase dump` или `ibcmd infobase restore`, база и
`.dt` не тронуты; без сеансов снимок снимается и загружается. Решение об отказе раннер
принимает по структурному сигналу (код выхода, состояние блокировки, ответ команды), а не
по тексту вывода платформы. Удерживается ли монопольный доступ на время работы `ibcmd`,
решает замер; до него правило обещает проверку до запуска.
