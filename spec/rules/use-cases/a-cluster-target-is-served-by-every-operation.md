# У кластерной цели есть исполнитель у каждой операции

У каждой операции матрицы непустая цепочка умолчаний и для файловой цели, и для кластера:
файловая база не единственный поддержанный путь.

Там, где серверного пути нет у самой платформы, отказ называется, а не обходится.
Ограничение «только файловая» живёт названным пробелом в `docs/CAPABILITIES.md`, а не
пустой строкой матрицы.
