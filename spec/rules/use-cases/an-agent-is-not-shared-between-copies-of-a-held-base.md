# Агент не делится между рабочими копиями базы, у которой есть владелец

Сессия агента Конфигуратора, открытая одной рабочей копией, другой копии той же файловой
базы не достаётся. Делить агента между копиями можно только на базе, объявленной общей
(`shared: true`). Это ограничение действует и для будущего пула агентов по базе.
