# Чужой агент отвечает отменой после конца своей команды

Команда, которую исполняет агент Конфигуратора, к которому раннер подключился (`attached`),
или шлюз SSH автономного сервера (`gate`), получает ответ `cancelled` только после
наблюдаемого конца этой команды на стороне агента. Если разрыв сессии команду не снимает,
раннер сессию не рвёт: он ждёт ответа агента на текущую команду и лишь тогда отвечает
`cancelled`, как при отложенной отмене.

Сегодня вне критической фазы раннер отвечает `cancelled` сразу по сигналу, затем шлёт
`common disconnect-ib` и закрывает соединение. Снимает ли это команду на стороне агента, не
замерено; методика — в
[замерах платформы](../../../references/1c/confirmed-runtime-measurements.md#отмена-у-чужого-агента-и-шлюза-ssh).
