# Занятый `regport` не заменяется молча

`cluster start` не берёт другой `regport` сам: занятый чужим процессом порт — отказ с его названием и ключом
`--new-regport`. Этот ключ заводит новый реестр и регистрирует объявленную базу без `--create-database` над
прежней БД: UUID базы меняется, данные и поколение конфигурации остаются. Если базы ещё нет, остаётся только
новый реестр. Прежний реестр удаляется после регистрации и успешной пробы базы, поэтому отказ на этом шаге ничего не теряет.
