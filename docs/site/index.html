Исходники 1С → действия над базой

Одна команда вместо связки Конфигуратора, ibcmd и EDT CLI. Раннер сам находит платформу и выбирает инструмент. Работает одинаково у человека, в CI и у ИИ-агента.

v8-runner config init     # найти исходники, записать конфиг
v8-runner init            # создать базу
v8-runner build           # загрузить изменения
v8-runner test yaxunit all

С чем работает

формат исходников

  • проект EDT
тип исходников
  • конфигурация
  • расширение
  • внешняя обработка
  • внешний отчёт
где база
  • файловая
  • кластер 1С
  • автономный сервер
что делаете
  • config init найти исходники, записать конфиг
  • init создать базу
  • build загрузить изменения
  • test прогнать тесты
  • dump выгрузить базу в исходники
  • load загрузить .cf или .cfe
  • make собрать .cf, .cfe, .epf, .erf
  • infobase configuration export конфигурацию базы в файл
  • infobase dump · restore снять базу в .dt и вернуть
  • extensions расширения базы
  • syntax проверка синтаксиса
  • publish опубликовать базу на Apache или IIS
  • launch запустить клиент или Конфигуратор
  • launch web открыть опубликованную базу в браузере
  • convert перевести исходники между форматами
