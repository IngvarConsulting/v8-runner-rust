Исходники 1С → действия над базой

v8-runner — программа командной строки, которая делает с базой 1С то, что вы делали бы руками через Конфигуратор, ibcmd и EDT CLI. Она сама находит платформу, выбирает инструмент и отвечает одинаково человеку, сценарию сборки и языковой модели.

# есть исходники, базы нет
v8-runner init              # найти исходники, записать конфиг
v8-runner infobase create   # создать базу по адресу из конфига
v8-runner push              # отправить исходники в базу
v8-runner test yaxunit all

# есть база, исходников нет
v8-runner clone --from "File=/srv/ib/demo"   # привязать каталог и выгрузить

Сайт описывает целевое состояние. Каждая страница говорит, каким раннер должен быть и почему. Расхождения с текущим кодом собираются отдельно и превращаются в план работ; здесь их нет.

Как читать

Страницы идут от платформы к командам. Каждая следующая опирается на предыдущую и ссылается на неё по номерам.

  1. Платформа — что утверждает документация 1С, по одному тезису на строку, каждый со ссылкой на ИТС.
  2. Трудности — что в поведении платформы мешает работать без рук, и чем раннер на это отвечает.
  3. Компоненты — из чего состоит система: компоненты платформы, её утилиты, сам раннер и каналы между ними.
  4. Исходники и база — какие бывают исходники, что им соответствует в базе, в каких состояниях они бывают.
  5. Словарь команд — вся поверхность командной строки и правило, по которому выбрано каждое имя.

Рядом: Подбор команд под ваши условия, Сценарии с потоками данных и Расстановки платформы по машинам.

что делаете
  • status понять, что происходит
  • init · clone завести проект
  • infobase create создать базу
  • push · apply отправить исходники в базу и применить
  • pull забрать изменения из базы
  • load загрузить пакет .cf или .cfe
  • make собрать пакет из исходников
  • check · test проверить и прогнать тесты
  • infobase save · infobase dump · infobase restore конфигурация базы в пакет, база в .dt и обратно
  • extensions · publish · launch · convert
