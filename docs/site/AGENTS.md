# Правила работы над справкой

- Описывайте согласованное целевое поведение. Текущая реализация не отменяет
  согласованные решения.
- Разрывы реализации и обходные пути для текущей сборки не включайте
  в публичную справку.
- Сохраняйте предметные ограничения и условия безопасности целевой модели.
- В `AGENTS.md` храните только устойчивые правила работы агента. Контракты команд,
  значения параметров и оформление принадлежат справке, спецификациям
  и руководству сайта.
- Перед завершением выполните проверки и вычитку, описанные в
  [README.md](README.md).
