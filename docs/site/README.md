# Сайт документации

Статический сайт, который публикуется на GitHub Pages workflow-ом
[`.github/workflows/pages.yml`](../../.github/workflows/pages.yml) при изменениях в этом каталоге.

- `index.html` — начало: что делает раннер, с чем работает, словарь.
- `scenarios.html` — команды под выбранные условия; данные в `data.js`.
- `usecases.html` — сценарии с потоком данных; данные в `usecases.js`, покрытие команд считается кодом.
- `architecture.html` — провайдеры и цели, правила выбора, слои, процессы, восемь вариантов развёртывания 1С,
  время жизни компонентов; `inside.html` остался перенаправлением сюда.
- `pairing.html` — на чём раннер останавливается: поколение базы, `ConfigDumpInfo.xml`,
  хеши исходников; кто их пишет и читает, и что бывает, когда точка отсчёта чужая.
- `site.js` — счётчик звёзд у ссылки на GitHub в шапке; кеш на час в `localStorage`.

Сайт описывает **целевое состояние**. В `data.js` рядом с целевой веткой сохранена ветка
текущего поведения — из их разницы собирается список работ.

Локальный просмотр:

```bash
python3 -m http.server 8765 -d docs/site
```
