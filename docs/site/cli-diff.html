Варианты ответа

Объекты изменились

Версия объекта изменилась относительно файла версий. Список описывает версии, а не содержимое. После push версии всех загруженных объектов новые, поэтому список называет все объекты, пока выгрузка не обновит файл версий. pull при неизменном поколении не выгружает; файл обновляет pull --force, который заменяет дерево исходников.
