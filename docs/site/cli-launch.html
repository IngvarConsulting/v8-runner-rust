launch

Откройте базу клиентом, Конфигуратором или браузером.

Вывод

Примеры ответов; пути и длительность зависят от запуска.

launch designer 

v8-runner launch designer

запускает клиент или Конфигуратор по строке подключения; --via web ведёт тонкий клиент по веб-адресу, другие клиенты через веб-сервер не ходят (67)

Классы ответов

Классы относятся ко всем вариантам этой команды; условия отдельных ключей указаны в строках. Примеры ниже показывают форму ответа, а не все сочетания настроек.

КлассКогда возникает и что означает
Клиент или браузер запущенPID при наличии относится к созданному процессу. Открытие браузера не проверяет доступность публикации.
Запуск запланированprovider_dispatched: false, PID не получен; plan содержит будущую программу и аргументы.
Клиент не запущенНеподходящая цель/ключи, отсутствующий веб-адрес, утилита не найдена или процесс не создан.
Готовность MCP-клиента подтверждена или не наступилаДля launch mcp --wait-ready проверяйте mcp_readiness.ok. Созданный процесс сам по себе не подтверждает готовность.
Ожидание внешней EPF завершеноПри запуске EPF с ожиданием external_epf_wait содержит exit_code, timed_out и пути журналов; отличается от простого получения PID. Завершение в срок не означает, что exit_code равен нулю.
Запуск или ожидание прерваныОтмена либо истёк срок ожидания. Процесс мог уже быть создан.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Операция завершилась успешно

Фрагмент успешного текстового ответа:

mode: designer
binary: /opt/1cv8/bin/1cv8
pid: 12345

Режим запуска не подходит цели

У отказа по цели может быть структурный следующий шаг error.next.

ERROR: capability unavailable: a standalone server is opened by its web address: use `launch web` with infobase.web.url; a client is not launched against the gate

MCP-клиент запущен, но готовность не подтверждена

Этот класс относится к launch mcp --wait-ready. При отказе готовности раннер завершает управляемый процесс; наличие PID в результате не обещает работающий клиент.

pid: 12345
MCP endpoint did not become ready
ERROR: runtime error: MCP endpoint did not become ready

launch web

v8-runner launch web

открывает опубликованную базу в браузере

Варианты ответа

Операция завершилась успешно

Фрагмент успешного текстового ответа:

mode: web
url: https://web.example/demo

launch designer --dry-run 

v8-runner launch designer --dry-run

Превью проверяет настройки и доступность исполнителя. Платформа не запускается; база и выходные файлы не меняются. Без --dry-run выполняется указанная операция.

Варианты ответа

План запуска подготовлен

Успех превью подтверждает подготовку плана, а не выполнение операции. Фрагмент текстового ответа:

mode: designer
binary: /opt/1cv8/bin/1cv8
provider dispatched: false

Команды, работающие с выбранной базой принимает --infobase <имя или строка>; без ключа берётся origin. В целевой модели План позиционные аргументы остаются за наборами исходников: push my-ext не должен гадать, ссылка это или база.
