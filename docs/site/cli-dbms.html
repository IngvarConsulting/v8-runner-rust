dbms

Команды dbms запускают и останавливают PostgreSQL для базы, объявленной dbms.managed, на машине раннера Windows, без службы и без прав администратора. Вашу СУБД раннер только использует и не трогает её процессы.

Вывод

dbms start

v8-runner dbms start

Запускает PostgreSQL из каталога tools.postgres.path и отдаёт ответ после того, как он принял соединение. При первом запуске создаёт каталог данных и пароль. Слушает только 127.0.0.1, вход — scram-sha-256. Порт выбирается вне динамического диапазона и закрепляется, потому что на него ссылается зарегистрированная база. Занят чужим процессом — команда отказывает и называет его, а переносить PostgreSQL на другой порт не умеет. PostgreSQL живёт между командами. Вид СУБД, адрес и пароль не объявляются. На Linux и macOS команда отказывает.

Если PostgreSQL уже запущен, команда ничего не запускает, но считает его явным: stop сервера его больше не трогает.

v8-runner dbms start --dry-run

Показывает каталог данных, журнал и закреплённый порт, если PostgreSQL уже запускался. Ничего не запускает.

dbms status

v8-runner dbms status

Отвечает, работает ли PostgreSQL базы из --infobase или origin; строка соединения в --infobase — отказ: не запущен, запускается, запущен раннером или порт занят не раннером. Для своей СУБД называет PID, адрес, имя пользователя, путь к файлу пароля и кто её поднял. Значение пароля не показывает. Замок рабочей копии команде не нужен. Ключа --dry-run у неё нет.

dbms stop

v8-runner dbms stop

Останавливает свой PostgreSQL и ждёт завершения его процессов. Данные остаются. С --dry-run показывает план и ничего не останавливает. Пока работает свой сервер этой базы, команда отказывает и называет его. Если PostgreSQL не запущен, останавливать нечего, и команда успешна; чужой процесс на этом порту она называет и не трогает.

dbms restart

v8-runner dbms restart

То же, что dbms stop и затем dbms start. Пока работает свой сервер этой базы, команда отказывает и называет его.

Данные лежат под workPath/infobases/<база>/managed/postgres/: удаление workPath уничтожает базу. Команды удаления данных у раннера нет.
