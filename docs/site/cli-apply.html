apply

Примените основную конфигурацию к базе данных после загрузки изменений.

Вывод

apply План

v8-runner apply

приводит базу данных к основной конфигурации и больше ничего (104)

Классы ответов

Классы относятся ко всем вариантам этой команды; условия отдельных ключей указаны в строках. Примеры ниже показывают форму ответа, а не все сочетания настроек.

КлассКогда возникает и что означает
Применение завершеноПрименение изменяет конфигурацию базы данных. Результат указывает основную конфигурацию как источник. Пример ответа.
Нужен монопольный доступЧужие сеансы мешают монопольному доступу; применение не выполнено. Пример ответа.
Применение с завершением сеансовВыбран короткий путь обслуживания: мешающие сеансы завершены перед применением. Пример ответа.
Завершение сеансов не разрешеноОперация не завершена: платформе не удалось завершить мешающие сеансы. Пример ответа.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Применение завершено

Применение изменяет конфигурацию базы данных. Результат указывает основную конфигурацию как источник.

origin: main
База данных приведена к основной конфигурации.

Нужен монопольный доступ

Чужие сеансы мешают монопольному доступу; применение не выполнено.

origin: main
Обнаружены чужие сеансы; изменения не применены.

apply --sessions disable|force План

v8-runner apply --sessions force

что делать с чужими сеансами, когда нужен монопольный доступ. По умолчанию их не трогают (4); полное окно обслуживания собирают команды sessions

Варианты ответа

Применение с завершением сеансов

Выбран короткий путь обслуживания: мешающие сеансы завершены перед применением.

origin: main
Мешающие сеансы завершены, изменения применены.

Завершение сеансов не разрешено

Операция не завершена: платформе не удалось завершить мешающие сеансы.

origin: main
Не хватает прав для завершения сеансов.

Настройка исполнителей и конфигурации проекта.
