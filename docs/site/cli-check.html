Проверьте конфигурацию или проект EDT.

Вывод

Примеры ответов; пути и длительность зависят от запуска.

check

v8-runner check

Выбирает проверку по формату проекта.

Формат исходников

Конфигуратор
Проверяет конфигурацию базы через /CheckConfig: целостность, ссылки, синтаксис, обработчики и модальность (79).
EDT
Проверяет проекты исходников через EDT CLI. Для выбора проекта используйте --project. Ключи режимов /CheckConfig здесь не применяются.

Классы ответов

Классы относятся ко всем вариантам этой команды; условия отдельных ключей указаны в строках. Примеры ниже показывают форму ответа, а не все сочетания настроек.

КлассКогда возникает и что означает
Проверка чистаяstatus: clean; проверка выполнена, проблем не найдено.
Найдены замечанияstatus: issues_found; issues/summary содержат ошибки, предупреждения и сообщения. Команда возвращает неуспех.
Проверка не дала вердиктаstatus: tool_failed: утилита не запустилась, завершилась с ошибкой или журнал нельзя прочитать. Это не «чисто».
Проверка запланированаstatus: planned; конфигурация ещё не проверена.
Проверка отклоненаНесовместимые ключи, формат или исполнитель; workPath занят.
Проверка прерванаОтмена или таймаут; вердикт о конфигурации не получен.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Операция завершилась успешно

Фрагмент успешного текстового ответа:

status: clean (exit 0, errors 0, warnings 0, info 0, duration 3 ms)

Найдены проблемы конфигурации

Вердикт issues_found отличается от сбоя инструмента. В JSON ошибка команды имеет kind: runtime; сами замечания находятся в data.issues.

status: issues_found (exit 101, errors 1, warnings 0, info 0, duration 3 ms)
[issue] CommonModules/Demo/Module.bsl:12 — Ошибка синтаксиса
ERROR: runtime error: syntax check 'designer-config' finished with status IssuesFound (exit code 101)

Журнал проверки не прочитан

Даже при exit_code: 0 неполученный журнал не позволяет заявить clean. Вердикт — tool_failed.

status: tool_failed (exit 0, errors 0, warnings 0, info 0, duration 3 ms)
[warning] log cannot read platform log
ERROR: runtime error: syntax check 'designer-config' finished with status ToolFailed (exit code 0)

check --dry-run

v8-runner check --dry-run

Превью проверяет настройки и доступность исполнителя. Платформа не запускается; база и выходные файлы не меняются. Без --dry-run выполняется указанная операция.

Варианты ответа

План проверки подготовлен

Успех превью подтверждает подготовку плана, а не выполнение операции. Фрагмент текстового ответа:

status: planned (exit -1, errors 0, warnings 0, info 0, duration 3 ms)
provider dispatched: false

check назван по тому, что делает платформа: /CheckConfig проверяет целостность, ссылки и обработчики, синтаксис — лишь часть (79). Слово «синтаксис» обещало бы меньше, чем приходит в ответе.
