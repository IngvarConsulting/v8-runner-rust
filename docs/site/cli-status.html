status

Начните с status, если непонятно, что происходит с проектом: команда показывает связь каталога с базой и расхождения между ними.

Вывод

status План

v8-runner status

Показывает, к какой базе привязан каталог, что разошлось и что потеряется при замене. Использует локальную память проекта: платформу не запускает и базу не меняет.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Обмена ещё не было

База объявлена в проекте, но сохранённого состояния ещё нет. Сравнивать исходники с прошлым обменом пока не с чем.

origin: File="/srv/ib/demo"

  main → ЖивоеИмяКонфигурации   нет сохранённого состояния — обмена ещё не было

Каталог привязан к базе

Показывает адрес базы и соответствие наборов исходников именам в базе. В этом примере изменений относительно сохранённого состояния нет.

origin: File="/srv/ib/demo"

  main   → ЖивоеИмяКонфигурации   совпадает
  my-ext → РасширениеВБазе        совпадает

Есть расхождения

Исходники изменились после последнего обмена. Команда называет изменённый набор; фактическое состояние базы без --deep не запрашивает.

origin: File="/srv/ib/demo"

  main   → ЖивоеИмяКонфигурации   3 файла изменено
  my-ext → РасширениеВБазе        совпадает

Что потеряется при замене

Показывает риск замены по сохранённым сведениям. Сама команда ничего не заменяет; для проверки актуального состояния базы нужен --deep.

origin: File="/srv/ib/demo"

  main → ЖивоеИмяКонфигурации   есть непринятое — будет потеряно при замене

status --deep План

v8-runner status --deep

Дополняет локальное состояние сведениями из базы: обращается к платформе, чтобы прочитать поколение конфигурации, состав расширений, наличие непринятых изменений и динамического обновления. Базу не меняет.

Варианты ответа

База совпадает с сохранённым состоянием

Поколение базы не изменилось; конфигурация и расширение соответствуют состоянию, известному проекту.

origin: File="/srv/ib/demo"

  main   → ЖивоеИмяКонфигурации   совпадает
  my-ext → РасширениеВБазе        совпадает

В базе есть непринятые изменения

Основная конфигурация изменена, но изменения ещё не применены к конфигурации базы данных.

origin: File="/srv/ib/demo"

  main → ЖивоеИмяКонфигурации   3 файла изменено · есть непринятое

База ушла вперёд

Поколение базы отличается от сохранённого после обмена. Перед отправкой исходников нужно забрать изменения командой pull.

origin: File="/srv/ib/demo"

  patch-01 → Patch_01   база ушла вперёд — сперва pull

Расширение есть в базе, но отсутствует в проекте

Слева стоит прочерк: у установленного расширения нет соответствующего набора исходников в проекте.

origin: File="/srv/ib/demo"

  — → Patch_007   есть в базе, нет в проекте

Конфигурация обновлена динамически

Платформа сообщает о динамическом обновлении конфигурации.

origin: File="/srv/ib/demo"

  main → ЖивоеИмяКонфигурации   обновлено динамически

status --all План

v8-runner status --all

Показывает состояние всех информационных баз, объявленных в проекте. Каждую базу рассматривает отдельно; платформу не запускает и базы не меняет.

Варианты ответа

В проекте одна база

Результат совпадает с status для этой базы: один адрес и состояние её наборов исходников.

origin: File="/srv/ib/demo"

  main → ЖивоеИмяКонфигурации   совпадает

Объявлено несколько баз

Каждая база выводится отдельной группой со своим адресом и состоянием. Изменения относительно памяти одной базы не подменяют состояние другой.

  main → ЖивоеИмяКонфигурации   3 файла изменено

test: Srvr="srv";Ref="demo_test"

  main → ЖивоеИмяКонфигурации   совпадает

С одной из баз ещё не было обмена

Для этой базы нет сохранённого состояния; остальные базы показываются по собственной памяти.

  main → ЖивоеИмяКонфигурации   совпадает

test: Srvr="srv";Ref="demo_test"

  main → ЖивоеИмяКонфигурации   нет сохранённого состояния — обмена ещё не было
