test

Запустите тесты в подготовленной базе.

Вывод

Примеры ответов; пути и длительность зависят от запуска.

test yaxunit / va

v8-runner test --no-push yaxunit

отправляет исходники и прогоняет тесты клиентом (83, 84); --no-push — только прогон

В примере --no-push отключает отправку исходников: тесты выполняются на уже подготовленной базе. Без этого ключа подготовка зависит от формата исходников — как у push.

Классы ответов

Классы относятся ко всем вариантам этой команды; условия отдельных ключей указаны в строках. Примеры ниже показывают форму ответа, а не все сочетания настроек.

КлассКогда возникает и что означает
Тесты пройденыreport содержит итоговые счётчики и результаты PASSED.
Некоторые тесты пропущеныSKIPPED — статус отдельного теста, а не сбой всего запуска. ERROR и FAILED — отдельные исходы кейсов; запуск без выбранных тестов может вернуть нулевые счётчики.
Проверки не прошлиerror_kind — test_failures; report сохраняет результаты FAILED / ERROR.
Подготовка сорваласьbuild_failed, infobase_unavailable или test_setup_failed: тесты ещё не выполнялись.
Клиент не выполнил прогонenterprise_spawn_failed, enterprise_startup_check_failed, enterprise_exited_early, enterprise_stdout_log_io, enterprise_stderr_log_io, enterprise_timed_out или enterprise_exited_non_zero.
Отчёт не получен или не разобранjunit_not_produced, junit_empty, junit_malformed. Это неизвестный результат прогона, а не «все тесты прошли».
Запрос отклонёнНесовместимые ключи/наборы, настройки или недоступный исполнитель/workPath.
Прогон прерванcancelled / timed_out; retained_paths и execution.artifacts помогают найти сохранённые материалы.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Операция завершилась успешно

Фрагмент успешного текстового ответа:

target: all
summary: total=1, passed=1, failed=0, skipped=0, errors=0

Настройка исполнителей и конфигурации проекта.

Тесты выполнены, есть провал

report сохраняет результаты. Это отличается от отсутствия отчёта или невозможности запустить клиент.

summary: total=1, passed=0, failed=1, skipped=0, errors=0
ERROR: runtime error: test assertions failed

Клиент не оставил отчёт

Результат тестов неизвестен. error_kind отличает отсутствие, пустой и повреждённый JUnit; retained_paths сохраняет адреса материалов запуска. Внешняя ошибка здесь runtime, хотя вложенный execution.status — invalid_output.

[error:junit_not_produced] JUnit report was not produced
[artifact] build/temp/yaxunit/runs/example/
ERROR: runtime error: JUnit report was not produced
