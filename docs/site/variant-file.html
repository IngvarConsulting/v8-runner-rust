Файловая база

Выберите вариант по расположению базы и утилит. Обозначения схем и настройки файлов проекта описаны отдельно.

Всё на одной машине: и раннер, и платформа, и каталог базы. Самый частый случай для разработчика и для CI, который поднимает базу с нуля.

Конфигурация

Основной файл v8project.yaml описывает исходники на машине раннера.

workPath: .build         # журналы, временные файлы и состояние
format: DESIGNER         # исходники в формате платформы
source-set:
  - name: main           # локальное имя набора
    type: CONFIGURATION  # основная конфигурация
    path: src/cf         # путь от каталога v8project.yaml

v8project.local.yaml рядом с основным файлом:

infobases:
  origin:
    connection: "File=.build/ib"  # база на машине раннера

Каталог .build/ib расположен рядом с проектом. Платформа установлена на той же машине.

Структура папок проекта

project/
├── v8project.yaml        # общие настройки проекта
├── v8project.local.yaml  # настройки этой машины и адрес базы
├── src/
│   └── cf/               # исходники конфигурации
└── .build/               # рабочий каталог раннера
    └── ib/               # файловая база
        └── 1Cv8.1CD      # файл базы данных
