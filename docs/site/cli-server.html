server

Команды server поднимают и останавливают автономный сервер ibsrv на машине раннера для базы, объявленной сервером под управлением раннера. К чужому ibsrv раннер только подключается и не трогает его процесс.

Вывод

server start План

v8-runner server start

Поднимает ibsrv той же платформы, что выбирают остальные команды (tools.platform), над файловой базой из standalone.server.db-path. Раннер сам выбирает свободные порты прямого шлюза, SSH-шлюза и HTTP, создаёт одноразовый ключ хоста для SSH-шлюза и отдаёт ответ только после того, как прямой шлюз принял соединение: готовность проверяется пробой, а не паузой (61, 65). Сервер живёт между командами, пока его не остановит server stop. Запись о том, какой процесс поднят, какими портами и с каким ключом, раннер держит под workPath.

Если сервер этой базы уже поднят раннером этой копии, команда ничего не запускает и называет его. Если базу держит чужой процесс ibsrv, команда отказывает и называет его: второй сервер над той же базой не поднимается.

v8-runner server start --dry-run

Показывает исполняемый файл, каталог данных, базу и выбранные порты. Ничего не запускает.

server status План

v8-runner server status

Отвечает, поднят ли сервер этой базы и кем: не поднят, поднят раннером этой копии или поднят не раннером. Для своего сервера называет PID, версию платформы, адреса прямого шлюза, SSH-шлюза и HTTP и прошла ли проба готовности. Чужой сервер только называет: чей он, раннер не знает. Платформу команда не запускает.

server stop План

v8-runner server stop

Останавливает сервер, который поднял раннер этой копии, и ждёт завершения его процесса. Сервер, поднятый не раннером, не останавливает: ответ называет его и говорит, что он не наш. Если сервер не поднят, останавливать нечего, и команда успешна.

server restart План

v8-runner server restart

То же, что server stop и затем server start, для своего сервера. Чужой сервер не перезапускает.
