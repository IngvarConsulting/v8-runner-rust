pull

Выгрузите основную конфигурацию базы в исходники.

Вывод

Примеры ответов; пути и длительность зависят от запуска.

pull --mode full

v8-runner pull --mode full --source-set main

Полная выгрузка основной конфигурации в выбранный набор исходников.

Формат исходников

Конфигуратор
Выгружает конфигурацию базы в XML-исходники платформы.
EDT
Выгружает конфигурацию базы в промежуточный XML и импортирует его в проект EDT.

Классы ответов

Классы относятся ко всем вариантам этой команды; условия отдельных ключей указаны в строках. Примеры ниже показывают форму ответа, а не все сочетания настроек.

КлассКогда возникает и что означает
Исходники выгруженыРезультат назван в target_path; при partial указаны selectors.
База не измениласьДля инкрементальной выгрузки up_to_date: true: выгрузка пропущена.
Результат получен с предупреждениемНапример, публикация завершилась, но уборка временных файлов не удалась; причина в message.
План подготовлен--dry-run не выгружает файлы.
Выгрузка не разрешенаНеверный набор/селекторы, неподходящий исполнитель или небезопасная замена цели.
Выгрузка или сохранение результата сорвалисьok: false; target_path не является доказательством готового результата.
Выполнение прерваноОтмена или таймаут. Успешно завершённая публикация может сохранить успех и сообщение об отложенном прерывании.
Слияние отклоненоПлан Обычный pull не теряет несохранённую работу; для EDT слияния нет. --force задаёт замену.

Причины отказов и различия между ошибкой команды, ошибкой шага и диагностикой запуска — в словаре ответов.

Варианты ответа

Исходники выгружены

source-set: main
mode: full
output: src/cf

Выгрузка пропущена

Этот ответ относится к инкрементальной выгрузке, а не к показанному выше --mode full. up_to_date отличает пропуск от выполненной выгрузки.

Dump skipped: configuration unchanged
source-set: main
mode: incremental
output: src/cf

Выгрузка не завершилась

target_path называет цель операции; при ok: false он не подтверждает готовность исходников.

source-set: main
mode: full
output: src/cf
Dump failed
ERROR: platform error: dump failed

pull План

v8-runner pull

База → исходники. Для формата Конфигуратора сливает пообъектно и отказывается, когда потерялась бы работа, которую система версий не вернёт. Для EDT слияния нет: выгрузка либо заменяет проект, либо отказывается. Подробнее — слияние и замена исходников.

Варианты ответа

Набор синхронизирован

Ответ называет базу, выбранный набор и результат обмена.

origin: Srvr="srv:1541";Ref="demo"
main: получен

pull --force План 

v8-runner pull --force

приводит каталог ровно к базе, уничтожая лишнее

Варианты ответа

Набор синхронизирован

Ответ называет базу, выбранный набор и результат обмена.

origin: Srvr="srv:1541";Ref="demo"
main: получен

pull --mode full --source-set main --dry-run

v8-runner pull --mode full --source-set main --dry-run

Превью проверяет настройки и доступность исполнителя. Платформа не запускается; база и выходные файлы не меняются. Без --dry-run выполняется указанная операция. Режим full выгружает выбранный набор целиком; обычный pull выполняет пообъектное слияние.

Варианты ответа

План выгрузки подготовлен

Успех превью подтверждает подготовку плана, а не выполнение операции. Фрагмент текстового ответа:

source-set: main
mode: full
output: src/cf

Настройка исполнителей и конфигурации проекта.
